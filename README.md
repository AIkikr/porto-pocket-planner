# Porto Pocket

ポルトガルのポルトを舞台にした、架空の旅のアイデアを表示する日本語デモです。実在の施設やイベント、他の顧客案件との関係はありません。旅行情報、予約サービスとしては使えません。

## 動かす

HTML、CSS、JavaScriptのみで動作します。インストール、APIキー、ビルドは不要です。プロジェクトのフォルダーで以下を実行し、表示されたURLをブラウザーで開きます。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

`python`が使えないWindows環境では `py -m http.server 8765 --bind 127.0.0.1` を試してください。停止は `Ctrl+C` です。

## GitHub Pages

推奨リポジトリ名: `porto-pocket-planner`。新しいリポジトリのルートに本フォルダー内のファイルを配置し、GitHubの Settings → Pages で、デプロイ元に `main` ブランチの `/ (root)` を指定します。公開URLはGitHubがPages画面に表示したものを確認してください。非公開リポジトリからの公開可否はGitHubプランによって異なります。

このデモでは選択をブラウザー内で処理し、アプリが外部へ送信したり、保存したりしません。ホスティング事業者の標準的なアクセスログは別です。実在情報や画像を追加する際は、出典・利用許諾と最新情報を確認してください。
